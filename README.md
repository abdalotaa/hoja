# Hoja

Note taker sobre un lienzo, construido con el design system de M4PL3. Next.js, pensado para Vercel.

```bash
npm run dev
```

## Estado

- Canvas con notas como ventanas: arrastrar, redimensionar, etiquetar, buscar.
- Guardado local en el navegador (`localStorage`).

## Siguiente

1. Cuentas y sincronización.
2. Captura por voz con resumen y pendientes.
3. Tarjetas de repaso y búsqueda por significado.
